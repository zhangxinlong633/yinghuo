# 太阳系链路与天线参考

DTN（束递）**不规定物理线**：Bundle Protocol 跑在会聚层（CLA）之上，底下可换射频、激光或地面 IP。本文按距离与角色，说明太阳系里**比较合适的物理层与天线**；萤火软件仍不造射频，星上电台／天线见 [`satellite.md`](./satellite.md)。

萤火现状：节点间是简化的 peer HTTP CLA + BPv7 CBOR；真实上天时把「板卡 → 电台」换成下表对应档即可。

## DTN 和「线」的关系

| 层级 | 常见形态 |
|------|----------|
| **物理／承载** | 射频（UHF／S／X／Ka）或激光；远距离不是网线直连 |
| **会聚层 CLA** | TCPCL、UDP、LTP 等（深空断链路常用 LTP 一类） |
| **束层** | BPv6／BPv7：关窗保管、开窗转发 |

## 按角色：太阳系里合适的天线

| 链路角色 | 合适天线／终端 | 典型波段 | 用在哪 |
|----------|----------------|----------|--------|
| **近地／立方星对地** | 可展开偶极／单极、贴片、小螺旋 | UHF／VHF／S | LEO 过境、业余电台；**萤火 1U 目标档** |
| **行星附近「最后一公里」** | 低增益螺旋／全向 | **UHF（约 400 MHz）** | 着陆器／巡视器 ↔ 轨道中继（Proximity） |
| **深空干线（火、木及以外 → 地球）** | 星上 **米级高增益抛物面（HGA）**；应急 **低增益（LGA）** | **X 为主，Ka 提速**；S 偏测控 | 轨道器／探测器对地球 |
| **地面深空站** | **34 m／70 m 级抛物面**（DSN 等） | S／X／Ka | 收极弱信号；外层几乎刚需 |
| **地月／未来高速干线** | 光学终端（飞行端几十 cm 口径级） | **激光（近红外）** | 高吞吐增强；与射频备份并用 |
| **星间中继** | 中等增益定向或宽波束 | UHF～X／光 | 中继星座之间 |

怎么记：

1. **远**（跨 AU）→ 星上 HGA（X／Ka）+ 地面大站；激光作高速加成。  
2. **近**（轨道器对着陆器、近地过境）→ UHF／业余小天线即可。  
3. **全太阳系一张网** → 多段拼接（近端 UHF + 远端 X／Ka／光 + 地面大站），用 DTN 保管，不是每颗星都背 70 m 碟。

## 地球 ↔ 火星

| 物理手段 | 适不适合 | 说明 |
|----------|----------|------|
| **X 波段射频** | **现在主力** | 深空网成熟；地火单向光时延约数分钟～二十多分钟，必须保管转发 |
| **Ka 波段射频** | **高速率射频首选之一** | 吞吐更高，雨衰／指向更挑 |
| **激光** | **很合适的高速增强** | 已有地火量级演示；需光学站网与精指向；路线图多是 **Ka + 光并行**，不是取代射频 |
| **UHF／业余 VHF** | **不适合作地—火直连** | 适合近地或火星「轨道器↔着陆器」近跳 |

常见业务拓扑：

**地球大站 ↔ 火星中继轨道器 ↔ 着陆器／巡视器**  

两跳都是射频（或将来光 + 射电），接触窗口 + DTN；很少假设地球与火星表面 7×24 直连。

萤火 1U + 业余电台只覆盖**近地／短跳演示**；地火干线换的是天线与站，不是把算力换成机房服务器。

## 地球 ↔ 太阳系边缘

一端地球、一端百 AU 量级（光时延约十来个小时），必须是**极不对称**配对：

| 端 | 合适天线 | 说明 |
|----|----------|------|
| **地球** | **DSN 级 70 m**（或 34 m 阵列） | 信号极弱，靠地面大口收 |
| **边缘探测器** | **米级 HGA**（约 3～4 m 量级经验）+ 有限功放；LGA 应急 | 探测器带不动大站，只能尖、稳地指回地球 |

波段长期主力仍是 **X**；Ka／光可谈但工程更重。业余 UHF、1U 线天线**扛不住**这一跳。下行往往只剩 **比特～百比特每秒** 量级，接触稀、时延以小时计，**DTN 保管是刚需**。
